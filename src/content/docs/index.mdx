Four things share the name "basix" — the distro, its package manager, and the personal
spins on its package repository:

| Thing | What it is | Upstream |
|---|---|---|
| **basix** | A small musl-based Linux distro ("basix linux") | [kkrruumm/basix-packages](https://github.com/kkrruumm/basix-packages) (package repo) |
| **bpm** | basix's package manager and build system | [kkrruumm/bpm](https://github.com/kkrruumm/bpm) |
| **FrankenBasix** | A community extension repository for basix ("a bunch of templates to make using basix nicer for me and other users") | [anoraktrend/frankenbasix](https://github.com/anoraktrend/frankenbasix) |
| **FrankenUTB** | Its untested sibling: "a bunch of untested basix package templates that others might like" (systemd replacements + Wayland stack, nothing built or verified) | [anoraktrend/frankenutb](https://github.com/anoraktrend/frankenutb) |

## Downloads

Prebuilt basix rootfs images are published on the helltop CDN. The `latest` URLs
always resolve to the newest build (via HTTP redirect); the dated paths are their
stable archive targets.

| Artifact | Latest | Dated (2026-08-12 build) |
|---|---|---|
| Rootfs tarball | [basix-rootfs-latest.tar.gz](https://cdn.helltop.net/basix-rootfs-latest.tar.gz) | [basix-rootfs-20260812.tar.gz](https://cdn.helltop.net/basix/2026-08-12/basix-rootfs-20260812.tar.gz) |
| BLAKE3 checksum | [basix-rootfs-latest.tar.gz.b3](https://cdn.helltop.net/basix-rootfs-latest.tar.gz.b3) | [basix-rootfs-20260812.tar.gz.b3](https://cdn.helltop.net/basix/2026-08-12/basix-rootfs-20260812.tar.gz.b3) |
| Installed packages | [basix-rootfs-latest.tar.gz.packages](https://cdn.helltop.net/basix-rootfs-latest.tar.gz.packages) | [basix-rootfs-20260812.tar.gz.packages](https://cdn.helltop.net/basix/2026-08-12/basix-rootfs-20260812.tar.gz.packages) |

Verify the tarball with `b3sum -c basix-rootfs-latest.tar.gz.b3`; the `.packages` file
lists the packages installed in the rootfs.

## Relationship at a glance

```
                kkrruumm/bpm (the engine, MIT)
                      │ interprets `template`s
      ┌───────────────┴─────────────────────────┐
basix-packages (core repo)   frankenbasix + frankenutb (overlays, shadow core)
      └───────────────┬─────────────────────────┘
                /etc/bpm/repos.conf priority → `bpm build/install`
```

- **basix** = the distro; **bpm** = the package manager + build system;
  **basix-packages** = the distro's package repo (`core`). basix is **decentralized**:
  community extension repositories provide extended functionality alongside core.
  **FrankenBasix** = a maintained extension repository, an overlay that extends/shadows
  basix-packages and adds bpm extensions; **FrankenUTB** = its untested sibling, a
  systemd-free/libudev-garden overlay that nobody has built yet.
- basix shares no package format with iglunix/frankensrc.
